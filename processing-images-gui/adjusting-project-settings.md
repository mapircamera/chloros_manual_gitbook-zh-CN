# 调整项目设置

在处理图像之前，请务必根据您的工作流程需求配置项目设置。通过“项目设置”<img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line">面板，您可以全面控制校准、处理选项、多光谱指数和导出格式。

## 访问项目设置

1. 在 Chloros 中打开您的项目
2. 点击左侧边栏中的 **项目设置** <img src="../.gitbook/assets/icon_project-settings.JPG" alt="" data-size="line"> 图标
3. “项目设置”面板将显示所有配置选项

**设置会随项目自动保存**。当您重新打开项目时，所有设置都会被恢复。
{% endhint %}

## 常见工作流的快速设置

### 默认设置（推荐给大多数用户）

默认设置适用于典型的 Survey3 和 LATTICE 工作流：

* ✅ **暗角校正**：启用
* ✅ **反射率校准/白平衡**：启用（使用 MAPIR 校准板和/或 DAQ 光传感器数据）
* ✅ **去拜耳算法**：标准（快速，中等质量）
* ✅ **导出格式**：TIFF（16 位）
* ✅ **所有导出产品**：已启用（LATTICE 会自动将数据拆分导出为去拜耳化、预览、辐射度和反射率文件）

只需导入您的图像，即可使用这些默认设置开始处理。

***

## 项目设置概述

“项目设置”面板分为以下几个部分。当您的项目包含相关文件时，另外两个部分——**DAQ 光传感器**和**阵列对齐**——会自动显示。如需完整的文档，请参阅 [项目设置](../project-settings/project-settings.md)。

### 显示

* **图像缩略图分辨率**：图像网格缩略图的分辨率。选项：**默认 (512 像素)**、**1024 像素**、**2048 像素**、**全分辨率**。 仅用于显示 — 绝不会影响处理。数值越高，放大后看起来越清晰，但加载速度越慢。

### 目标检测

控制 Chloros 如何在图像中识别校准目标。

**关键设置：*** **最小校准采样区域 (px)**：目标检测的大小阈值（默认：**25**，范围 0–10000）
* **最小目标聚类值 (0-100)**： 将目标区域分组的相似度阈值（默认：**60**）**何时调整：**

* 若出现误检测，请增大采样面积
* 若目标无法被检测到，请减小采样面积
* 若目标被拆分为多个检测结果，请调整聚类阈值

{% hint style="info" %}
当**反射率校准/白平衡**关闭时，这些设置将显示为灰色——若关闭该功能，目标检测将完全无法运行。
{% endhint %}

### 处理

主要的图像处理和校准选项。

**关键设置：*** **暗角校正**：补偿镜头边缘的变暗现象 ✅ 推荐
* **反射率校准/白平衡**：利用检测到的目标（Survey3）和/或 DAQ 光传感器数据（LATTICE）对图像进行校准 ✅ 建议使用
* **去拜耳算法**：将 RAW 格式转换为 3 通道多光谱格式的算法
* **最小重新校准间隔**：使用校准目标之间的最小时间间隔（单位：秒）（默认：**0** = 全部使用，范围 0–3600）**未校准的备用产品：**当无法对帧进行反射率校准时（无可用目标，或校准已禁用），该帧将作为两种备用产品之一导出——**每次运行仅存在其中一种**，具体由“暗角校正”开关决定：

* **导出传感器响应**：写入 `Sensor_Response_Images` — 用于**关闭** 暗角校正时
* **导出暗角校正后的数据**：写入 `Vignette_Corrected_Images` —— 用于暗角校正功能**开启**时

当前未启用的复选框将显示为灰色。取消勾选当前启用的选项将完全停止该文件的写入。

**LATTICE 导出产品**（每个项目都会显示；适用于 LATTICE 捕获的数据）：

* **导出去拜耳化图像**：线性去拜耳化图像（`Debayered_Images`）。适用于 RGB 及多光谱模块。
* **导出预览**：显示预览（`Preview_Images`）。RGB = 白平衡（如有可用，则采用DAQ光源；否则采用灰度世界）+ 伽马校正；多光谱 = 假色拉伸。
* **导出辐射度**：float32 谱辐射度（`Radiance_Images`，W/m²/sr/nm）。仅限多光谱模块——不适用于 RGB 主模块。
* ****导出反射率**：uint16 反射率（`Reflectance_Calibrated_Images`，DN 32768 = ρ 1.0），当 `.daq` 下行辐射读数或帧内目标覆盖整个帧时。 仅限多光谱模块。

这四项均**默认开启**——单次处理过程中，一个导入的 LATTICE 原始帧将扇出至所有已启用且适用的产品。当“反射率校准”关闭时，“**导出反射率**”复选框将显示为灰色。 若父级开关导致某项设置无法启用，该设置将始终显示为灰色，并附有提示气泡说明需修改的开关名称。**高级设置：*** **光传感器时区偏移**：用于光传感器时间匹配的 UTC 时差（默认：0，范围 −12 至 +12）
* **应用 PPK 校正**：使用 `.daq` 文件中的 GPS/曝光定位点数据（默认：关闭）
* **曝光定位点 1/2**：在双摄像头设置中将摄像头分配给曝光定位点

{% hint style="info" %}
**LATTICE 输入级别为自动。** LATTICE 捕获的图像会在 XMP 元数据中携带其处理级别，且处理始终在原始帧阶段进入处理管道——GUI 中无需进行任何配置。 （标志 CLI 和 `--input-level` 作为高级用户的覆盖选项，用于元数据丢失的捕获； 请参阅 [CLI 参考文档](../reference/cli-reference.md)。)
{% endhint %}

### 去拜耳化方法

目前我们在 Chloros 中提供 2 种去拜耳化方法：

#### 标准（快速，中等质量）

标准去拜耳化处理速度快，但会出现去拜耳化色彩噪点，导致图像精度较低且噪点较多。

#### 纹理感知（速度慢，最高质量）\[仅限Chloros+\]

纹理感知方法采用高质量的边缘感知去拜耳算法，并结合 AI/ML 降噪模型，可消除几乎所有的去拜耳噪声。 该模型运行需要 GPU 内存（VRAM）：若 **VRAM 容量为 7 GB 或以上**，可同时处理多张图像；若低于 7 GB，则每次仅处理一张图像（速度明显变慢）。 参见 [动态计算自适应](../processing-architecture/dynamic-compute-adaptation.md)。

{% hint style="info" %}
**LATTICE 捕获的图像始终使用标准去马赛克处理。** 目前尚无针对 LATTICE 训练的“纹理感知”模型，因此该选项不适用于 LATTICE 图像——但同一项目中的 Survey3 图像仍可使用该功能。
{% endhint %}

### 指数（多光谱指数）

配置要计算和导出的植被指数。图形用户界面的下拉菜单提供了**27个预定义的指数公式**。**如何添加指数：**

1. 点击**“添加指数”** 按钮
2. 从下拉菜单中选择一个指数（NDVI、NDRE、GNDVI 等）
3. 配置可视化设置（LUT颜色、数值范围）
4. 根据需要添加多个指数

**常用指数：*** **NDVI**：总体植被健康状况 （最常见）
* **NDRE**：配合 RedEdge 进行早期压力检测
* **GNDVI**：对叶绿素浓度敏感
* **OSAVI**：适用于可见土壤
* **EVI**：叶面积指数（LAI）较高的区域**自定义公式：**

* 通过所有图像波段的波段运算创建自定义多光谱指数公式
* 保存自定义公式以便重复使用
* 自定义公式是 Chloros+ 功能；是否可用取决于您的套餐等级

有关所有可用指数和公式（包括哪些名称仅限 GUI 使用，哪些也适用于 CLI/SDK），请参阅 [多光谱指数公式](../project-settings/multispectral-index-formulas.md)。

### 导出

控制输出文件格式。

**可用格式**（设置：**校准图像格式**，默认**TIFF (16 位)**）：

* **TIFF (16 位)**：推荐用于 GIS 和科学分析
* **TIFF (32 位，百分比)**：浮点数值
* **PNG (8位)**：用于可视化的无损压缩
* **JPG (8位)**：文件大小最小，有损压缩

输出文件保存在项目文件夹下，按相机和格式分组：`<project>/<camera>/<format>/<Product>_Images/`。无论此设置如何，辐射度数据**始终**以 float32 格式写入 `tiff32` 文件夹。 导出文件保留源文件名——文件夹用于标识产品。完整的输出目录结构请参见 [完成处理](finishing-the-processing.md)。

{% hint style="warning" %}
**读取反射率值**： 表示 ρ = 1.0 的动态范围 (DN) 取决于源相机——LATTICE 使用 32768（标记为 XMP `Chloros:PixelScale`），Survey3 使用 65535。 请读取标签值，而非假设其为常量。参见 [输出图像格式](../output-image-formats.md)。
{% endhint %}

### DAQ 光传感器

本节列出了项目中的每个 DAQ 下行辐射文件（`.daq` / `.csv`），每行一个文件，显示传感器模型、文件名以及该文件生效的漫射器**盖**校正值。

* **校正值覆盖（所有文件）**：一个适用于整个项目的下拉菜单。**自动**（默认）使用每个文件记录的校正值——若未记录任何数据，则默认采用“阳光”校正值，因为所有 MAPIR DAQ 设备均自带“阳光”校正器。 选择一个上限值将覆盖所有文件：原始记录将以此进行校正，而已包含上限值的记录将被重新校准（即撤销已记录的校正，并应用所选上限值）。
* 当记录的校准值是集线器的默认值而非操作员确认的值时，以及当所选校准值没有该设备型号的配置文件时（系统将拒绝对该文件进行覆盖），行会显示警告。

在“光传感器”选项卡中生成的 DAQ 记录会自动添加到当前打开的项目中，而导入的 `.daq` / `.csv` 文件一经添加即会显示在此处。

此部分**仅**在项目中至少有一张图像包含 LATTICE 阵列在捕获时标记的模块间对齐变换（`Chloros:Alignment*` XMP）时才会显示。 该部分显示了带有标签的图像数量以及参考相机，并提供以下控制选项：

* **应用阵列对齐**（默认：开启）：将每个处理后的产品（去拜耳化/预览/辐射度/反射率/指数）变换为阵列的共享参考几何结构。关闭 = 以原生传感器几何结构导出。
* **裁剪至共同重叠区域**（默认：开启）：将对齐后的导出结果裁剪至所有模块共有的区域，从而确保每个波段具有相同的覆盖范围。关闭时保留完整的传感器画布（源图像外侧填充黑色）。
* **重采样**：**双线性（平滑，默认）**、**最近邻（保留精确值）**— 不进行像素间混合，适用于严格的辐射度分析 — 或**三次插值（最锐利）**。***

## 保存和加载设置

### 保存项目模板

创建可重复使用的模板以确保工作流程的一致性：

1. 在“项目设置”面板中配置所有所需设置
2. 滚动至底部的 **“保存项目模板”** 部分
3. 输入一个描述性模板名称（例如，“Survey3N\_RGN\_Agriculture”）
4. 点击保存图标

**优势：**

* 在多个项目中应用相同的设置
* 与团队成员共享配置
* 确保重复调查的一致性

### 在新项目中加载模板

创建新项目时：

1. 从主菜单中选择 **“新建项目”**

2. 在可选的模板选择器中选择一个项目模板
3. 模板中的所有设置将自动应用

### 工作目录

**“工作目录”**设置指定了新项目默认创建的位置：

* **默认位置**：`C:\Users\[Username]\Chloros Projects`
* **更改位置**：点击编辑图标并选择新文件夹
* **与 CLI 共享**：`chloros-cli` 将使用相同的默认项目文件夹设置
* **何时更改**：
  * 用于团队协作的网络驱动器
  * 存储空间更大的其他驱动器
  * 按年份/客户整理的文件夹结构

## PPK（后处理动态定位）设置

如果使用带 GPS 的 MAPIR DAQ 记录仪进行精确定位：

### 先决条件

* 配备 GPS（GNSS）模块的 MAPIR DAQ
* 包含曝光引脚条目的 .daq 日志文件
* 拍摄期间相机已连接至 DAQ 的曝光引脚

### 配置步骤

1. 将 .daq 日志文件放置在项目文件夹中
2. 在“项目设置”中，勾选 **“应用 PPK 校正”** 复选框
3. 如有需要，设置 **“光传感器时区偏移”**（默认：0，即 UTC）
4. 将相机分配至曝光引脚：
   * **单相机**：自动分配至引脚 1
   * **双相机**：手动将每台相机分配至正确的引脚**曝光引脚分配：*** **曝光引脚 1**：从下拉菜单中选择相机型号
* **曝光引脚 2**：选择第二台相机或“不使用”
* 同一台相机不能分配给两个引脚

{% hint style="warning" %}
**重要提示**：必须将曝光引脚正确分配给相应的摄像头。分配错误将导致地理位置数据不准确。
{% endhint %}

## 高级场景

### 多摄像头项目

在同一个项目中处理来自多台 MAPIR 相机的图像时：

1. Chloros 会自动检测每台相机的型号（包括 Survey3 和 LATTICE 等）
2. 每台摄像机将获得相应的处理配置文件，并拥有独立的输出文件夹树
3. PPK：手动将每台 Survey3 摄像机分配到正确的曝光引脚
4. 所有摄像机使用相同的导出格式和索引

**示例**：Survey3W、RGN + Survey3N、OCN 双摄像头支架， 或混合使用 RGB 主相机与窄带模块的 LATTICE 阵列

### 延时摄影或多日期观测

针对同一区域随时间推移的重复观测：

1. 创建包含标准设置的模板
2. 每次拍摄均采用一致的校准目标设置
3. 将每个日期作为独立项目进行处理
4. 使用相同的设置以获得可比结果
5. 以相同格式导出数据以便进行时间序列分析

### 大型数据集

对于包含大量图像（500+）的项目：

* 考虑按日期或区域拆分为多个小型项目
* 使用 Chloros+ 并行处理以加快处理速度
* 考虑使用 CLI 或 API 实现批量自动化
* 调整最小重新校准间隔以缩短目标检测时间
