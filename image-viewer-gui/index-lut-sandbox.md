# 索引/LUT 沙盒

索引/LUT 沙盒是 Chloros 图像查看器侧边栏中的交互式工作区。 您可以选择一个公式，将相机的通道绑定到该公式上，使用渐变色进行调色，并调整数值范围——操作过程中图像会实时更新。自 1.2.0 版本起，您还可以**保存所做的设置**，无论是针对单张图像还是整个项目，且无需重新处理。

## 沙盒的功能

| 索引/LUT 沙盒（交互式）        | 项目处理（批处理）       |
| -------------------------------------- | -------------------------------- |
| 每次处理一张图像，即时反馈  | 一次性处理整个数据集     |
| 实验性与迭代性             | 预配置设置          |
| 实时渲染；仅在您要求时保存  | 始终写入输出文件      |
| 非常适合寻找合适的设置        | 最适合在设置最终确定后使用 |

{% hint style="success" %}
**常规工作流程**：在“沙盒”中调整参数，直到可视化效果符合预期，然后直接从“沙盒”导出，或者将相同的索引和 LUT 设置复制到 [项目设置](../project-settings/project-settings.md)，以便下次处理时将这些设置应用到每张图像中。
{% endhint %}

## 打开 Sandbox

1. 点击网格中的任意图像——它将在 **图像查看器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 标签页中全屏打开
2. 若左侧边栏尚未打开，请点击 **图像查看器** <img src="../.gitbook/assets/icon_image-viewer.JPG" alt="" data-size="line"> 图标将其滑出
3. 从右上角的图层下拉菜单中选择一个多波段图层 —— **RAW（反射率）** 是通常的选择，因为基于校准反射率计算的指数值在不同图像之间具有可比性

侧边栏从上到下显示：

* 图像名称及其相机型号
* **导出/保存图像** 按钮 —— 勾选“指数”或“LUT”后显示
* **指数**和**LUT** 复选框
* 指数配置面板
* 包含读数、直方图和 GSD 控制的 **光标值** 面板

{% hint style="warning" %}
**不适用于单色相机。** 在单波段 LATTICE M3M 图像上，这两个复选框均处于禁用状态，并显示工具提示 _“不适用于单色 (M3M) 传感器”_ —— 单波段图像无法定义多波段索引。 要从 M3M 相机计算指数，请将两个或多个图像组合成对齐的多波段堆栈，并使用 LATTICE 指数引擎。
{% endhint %}

## 应用指数

1. 勾选侧边栏顶部的 **指数** 复选框
2. 从左侧下拉菜单中选择相机的滤光片（`RGN`、`OCN`、 `NGB`、`RGB`、`RE`、`NIR`）
3. 从右侧下拉菜单中选择一个索引公式——包含 27 个内置公式，以及您已保存的任何自定义公式
4. 公式将以下方数学表达式形式呈现，每个波段槽位处有一个空心圆。 **将彩色通道圆圈拖动到插槽上**以进行绑定
5. 当公式中使用的所有插槽均已绑定后，图像将更新并显示索引值
6. 将光标悬停在图像上可查看数值；**光标值**面板会添加一行索引，显示光标下方的数值

双击已绑定的插槽可将其清空。公式未完成属于正常的拖拽过程中状态，并非错误——在公式完成之前，图像仅不会更新。

通道圆圈采用颜色编码：红色 = Red， 绿色 = Green，蓝色 = Blue，橙色 = Orange， 青色 = Cyan，紫色 = NIR，品红色 = RE。光标值面板中的通道点和直方图曲线也使用相同的颜色。

### NDVI 示例

```

Formula: (NIR - Red) / (NIR + Red)

For a Survey3W RGN camera:
  NIR = 850 nm band
  Red = 661 nm band

Result range:          -1.0 to +1.0
Typical vegetation:     0.4 to 0.9
Stressed vegetation:    0.2 to 0.4
Bare soil:              0.0 to 0.2
Water:                 -0.1 to 0.1
```

有关完整的公式参考——包括全部三个预设列表以及各名称在何处适用——请参阅 [多光谱指数公式](../project-settings/multispectral-index-formulas.md)。

### 勾选“指数”但未使用 LUT 时

图像以**灰度**形式绘制，并在两个阈值之间进行拉伸。这是有意为之：指数图像属于标量数据，而灰度是其最真实的呈现方式。若需显示颜色，请添加 LUT。***

## 使用 LUT （查找表）**查找表** 将索引值映射为颜色：输入 NDVI 0.65，输出特定的绿色。它不会改变数据本身——而是改变你读取数据的方式。

### 添加 LUT

1. 点击公式下方的 <img src="../.gitbook/assets/image (1) (1) (1).png" alt="" data-size="line"> **“+ 添加 LUT”** 按钮
2. 选择一种颜色渐变
3. 设置剪切的最小值和最大值
4. 选择剪切模式
5. 勾选侧边栏中的 **LUT** 复选框以渲染效果

在索引上实际配置好 LUT 之前，LUT 复选框将保持禁用状态。

### 选择颜色渐变

将鼠标悬停在 **渐变条**上以打开预设列表 — Chloros 提供了**七种** 渐变预设：

| # | 渐变                            | 形状                                                               |
| - | ----------------------------------- | ------------------------------------------------------------------- |
| 1 | Red → 黄色 → Green（**默认**）  | 发散型 — 符合常见的植被直观认知，绿色 = 健康 |
| 2 | 紫色 → 黄色 → Green             | 发散型，低端范围明显                                  |
| 3 | 棕色 → 白色 → Blue                | 以较浅的中点为中心呈发散型                                   |
| 4 | 黑色 → 紫色 → 粉色 → 淡黄色 | 顺序型，由暗至亮                                           |
| 5 | Red → 黄色 → Blue                 | 围绕浅色中点呈发散型                                   |
| 6 | 紫色 → Blue → Green → 黄色      | 顺序变化，由暗至亮                                           |
| 7 | Orange → 白色 → 紫色             | 围绕较浅的中点发散                                   |

**发散型**渐变会在窗口中间放置一种中性色，当中点具有特定含义（如阈值、基准日期）时，这种渐变效果很好。**顺序型**渐变则以单调递增的方式从深到浅过渡，对于仅表示“多”和“少”的量来说，这种渐变效果很好。

每个预设包含七个颜色停点。点击预设后，图像会立即更新（当勾选了 LUT 复选框时）。

### 编辑颜色停点

渐变条下方是一排颜色色块，每个停点对应一个色块：

* **更改颜色**：点击色块可打开颜色选择器（色轮、RGB/HSV 滑块，或十六进制代码，例如 `#FF0000`）
* **添加色阶**：点击该行末尾的**+** 按钮——将追加一个白色色阶
* **删除色阶**：**双击**色块
* **保留已编辑的渐变**：点击渐变条旁边的保存图标，将编辑后的渐变添加到预设列表中，以便日后再次选用

您在索引上配置的渐变会与该索引一同存储在项目设置中，因此即使关闭并重新打开项目，该渐变也会保留。

**停点较少**会形成分明的分区，呈现分类效果；**停点较多**则会产生平滑、近乎照片般的过渡效果。三到五个停点适用于演示幻灯片和分类图；六到十个停点适用于一般分析；十五个或更多停点则适用于详细检查和出版图表。

### 设置数值范围

阈值控件是一个从 −1 到 +1 的 **双控点滑块**，两端各有一个可编辑的文本框用于输入精确数值，并配有一个**AUTO** 按钮。

* 拖动任一滑块，或在文本框中输入数值后按 Enter 键
* **AUTO**将范围设置为图像有效索引值的**第 2 百分位数和第 98 百分位数** ——这是一个忽略异常值的良好起点。Chloros 会自适应地将结果四舍五入：对于非常窄的范围，保留 4 位小数；对于窄范围，保留 3 位小数；其他情况则保留 2 位小数
* 任何手动调整都将优先于“AUTO”模式，直到您再次点击“AUTO”

示例 NDVI 窗口：

| 目标                                    | 最小  | 最大 |
| --------------------------------------- | ---- | --- |
| 显示所有内容                         | −1.0 | 1.0 |
| 仅显示植被，排除土壤和水体 | 0.2  | 0.9 |
| 仅显示健康植被                 | 0.5  | 0.9 |
| 突出显示受胁迫植被             | 0.2  | 0.5 |

缩小窗口范围会提高目标区域内的对比度，并将其他所有内容推至范围之外——此时由**裁剪模式**决定这些内容的处理方式。***

## 裁剪模式

当像素的索引值超出最小/最大范围时，裁剪模式将决定其绘制方式。

| 下拉菜单标签                  | 存储值      | 超出范围的像素将绘制为                                                                                                |
| ------------------------------- | ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **最小值与最大值**（默认） | `clip`            | 渐变的最近端颜色——小于最小值的像素采用第一种颜色，大于最大值的像素采用最后一种颜色 |
| **透明背景**      | `transparent`     | 完全透明（真实透明度）                                                                                                  |
| **索引背景**| `indexColor`      | 灰度，拉伸至图像的**完整**索引范围，因此超出范围的结构仍以灰色显示                |
| **原始背景**         | `backgroundColor` | 底层图像本身，因此颜色叠加层位于真实场景之上                                                |

| 模式                       | 最适合                               | 外观                                      |
| -------------------------- | -------------------------------------- | ----------------------------------------- |
| **最小值与最大值**      | 完整数据显示，科学分析 | 每个像素均着色                      |
| **透明背景**           | GIS 叠加层，隔离特定数值区间   | 窗口内为彩色，窗口外无显示 |
| **索引背景**       | 突出显示同时保留数据上下文    | 窗口内为彩色，窗口外为灰色               |
| **原始背景**    | 报告和演示文稿              | 窗口内为彩色，照片外为灰色         |

{% hint style="info" %}
**在所有模式下，无数据像素始终为透明。** 索引值非有限（即 0/0 除法）或恰为 −1.0 或 +1.0（饱和度哨兵值，由一个波段读数为零而另一个波段读数不为零所致）的像素，将被视为无数据而非极值。 这可避免过曝的高光和死黑部分进入您的色彩范围，而不是将其渲染为帧内最极端的读数。同一规则还定义了哪些像素用于计算 AUTO 阈值和索引直方图，因此这三者保持一致。
{% endhint %}

当以 PNG 格式导出时，透明度得以保留。JPG 格式无法表示透明度。

## 调整时的数值读取

配置面板下方的**光标值**面板是 Sandbox 的测量工具：

* 将光标移至图像上，即可读取各通道的源值，以及位于单独一行中的索引值
* 点击直方图上方的 **INDEX** 按钮，即可查看帧内索引值的分布情况，其中两个剪切阈值以橙色虚线显示，光标值则以白线显示——这是选择实际包含您数据的窗口最快捷的方式
* 启用 **CURSOR** 以在光标下方的数值处显示标记线
* 将放大倍率调至 60× 以上（若设置了 GSD 块大小，则需调低），以突出显示带有浮动值的单个像素

实用操作流程：

1. 记录健康植被、受胁迫植被、裸土和水体上方的数值
2. 观察这些聚类在指数直方图中的位置
3. 设置最小值/最大值以包围您关注的聚类
4. 选择裁剪模式——_原始背景_可保留其周围场景的可见性

## 从沙盒导出

在保存之前，上述所有内容均为实时预览。侧边栏顶部的 **“导出/保存图像”** 按钮会打开一个滑动面板，该面板会覆盖在侧边栏上方（而非遮挡图像，因此您仍可看到正在处理的内容）。

<figure><img src="../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>### 选项

| 选项                          | 效果                                                                                                                                            |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| **应用于当前图像**      | 根据这些设置，精确保存当前显示的图像                                                                                                |
| **应用于项目中的所有图像** | 对项目中的每张图像重新应用相同的配置。缺少该索引所需波段的图像将被跳过，不视为处理失败 |
| **索引/LUT 渐变条**      | 每次导出时还会生成一张单独的图例图像，并标注数值范围                                                                     |
| **索引直方图**             | 每次导出时还会生成一张单独的直方图图像，显示数据的最小值/最大值以及剪切阈值                                               |

如果图像选项卡中的 **GSD 块大小** 大于 1，在您确认操作之前，面板会提示此信息：导出将保存您当前所见的图像，其中包含块平均处理。若需全分辨率，请先将 GSD 控件重置为 1。

### 文件存储位置

每次点击 **导出**都会分配一个**全新的、永不重复使用的文件夹**：

```
<project folder>/Sandbox_Exports/<IndexName>_<Index|LUT>_<NNN>/
```

示例：`Sandbox_Exports/NDVI_LUT_001/`，下次运行时则为 `Sandbox_Exports/NDVI_LUT_002/`。编号是根据磁盘上已有的文件扫描生成的，因此即使重启或手动删除文件夹，该编号也会保留。 绝不会覆盖任何内容——沙盒的核心功能正是将当前尝试与上一次进行对比。

文件夹内，每张图像对应：

| 文件                                                   | 内容                                                   |
| ------------------------------------------------------ | ---------------------------------------------------------- |
| `<source name>_<IndexName>_<Index\|LUT>.png`           | 渲染后的图像，与查看器显示的内容像素对像素完全一致 |
| `<source name>_<IndexName>_<Index\|LUT>_legend.png`    | 若被请求，则包含渐变条旁路文件                     |
| `<source name>_<IndexName>_<Index\|LUT>_histogram.png` | 若被请求，则包含索引直方图旁路文件                  |

这两个辅助文件始终以**全分辨率**写入，即使主图像经过块平均处理也是如此：块大小即为显示分辨率，且这两个辅助文件均读取真实的每像素索引值。 它们显示的信息也比屏幕上的版本更全面——两者都会标注拉伸窗口_以及_真实数据的最小值和最大值，因此即使数月后未打开该项目，保存的图例依然清晰可读。

### 进度与结果

整个项目的导出只需几分钟，因此运行过程会通过实时进度通道反馈进度，而非阻塞程序：

* 进度条显示 `current / total` 以及正在写入的文件
* 完成后，面板会报告导出的图像数量、被跳过的图像数量以及输出文件夹路径
* 被跳过的图像会列出原因（最多显示五条，之后显示“+N 条”一行）。常见原因是图层中缺少该索引所需的通道
* 如果项目中**没有任何**图像能使用该索引，运行将报告失败，而非留下一个空文件夹

每次仅允许一个沙盒导出任务运行。当一个任务正在进行时，若尝试启动第二个任务，系统会显示明确的拒绝信息，而非让两个任务争夺同一个项目文件。

### 网格会自动显示运行结果

每个已完成的运行都会以独立按钮的形式出现在 [图像网格](image-grid.md) 工具栏中，标签为 `<IndexName> <Index|LUT> <NNN>`。 这就是比较运行结果的方式：使用不同的梯度或阈值进行两次导出，然后在网格上的两个按钮之间切换。

## 自定义索引公式 (Chloros+)

{% hint style="info" %}
**创建位置**：在“沙盒”侧边栏中，或在处理前进入**项目设置**。两者都会写入同一项目级列表。
{% endhint %}

1. 从索引公式下拉菜单中打开自定义公式计算器 （需要使用符合条件的 Chloros+ 订阅登录）
2. 使用 **频段槽位符号** `x`、`y`、 `z`、`y`、`a`、`b`、`c` — 注意：这些不是频段名称
3. 可用运算符：`+`、`-`、`*`、`/`、 `^` 以及 `()`（用于分组）
4. 可用函数：`sqrt()`、`log()`、 `ln()`、`abs()`、`sign()`、`log1p()`、`log2()`
5. 命名并保存该公式——它会出现在公式下拉菜单的底部，您可以通过拖动通道圆圈来绑定其插槽，操作方式与内置预设完全相同

```

Modified NDVI with an offset:   (y-x)/(y+x+0.5)
Simple ratio:                   y/x
Three-band difference:          (y-x)/(y+x-z)
Squared ratio:                  (y/x)^2
```

{% hint style="warning" %}
**自定义公式仅限图形用户界面（GUI）使用。** CLI/SDK `--indices` 选项会扩展 22 个内置预设名称，并自动跳过其他所有内容，包括您的自定义公式。 若要批量处理自定义公式，请在“项目设置”中进行配置并运行处理，或使用“沙盒”中的“应用到所有项目图像”导出功能。
{% endhint %}

## 故障排除

### “该图层不包含此索引所需的通道”

公式读取了当前图层不具备的通道位置——例如，在一或两通道文件上使用三槽索引。 请切换到多波段图层（反射率或去拜耳化），或选择与您的相机滤镜相匹配的索引。

### “无法连接到图像处理后端”

后端未响应。 请检查“日志”选项卡；如果后端正在重启，一旦恢复，Sandbox 会自动恢复正常。

### 拖动圆圈时图像没有变化

公式尚未完成。不完整的公式会被视为正常的拖动中间状态——既不会渲染，也不会报告错误。 请填满公式中使用的所有槽位。

### 整张图像呈现单一颜色

您的剪切窗口可能远超出数据范围。点击 **AUTO**将其对齐至第 2 百分位或第 98 百分位，或开启**INDEX** 直方图以查看数据的实际分布范围。

### 导出的颜色与我看到的不同

它们应该是一致的——导出路径是实时预览的刻意镜像，包括剪切模式的透明度，且块平均处理是在着色_之后_应用的，这与查看器中的处理方式完全一致。 如果存在差异，请检查在查看和导出过程中 GSD 块大小是否发生了变化。
